# গ্যালারি ছবি এখানে রাখুন
নাম দিতে হবে ঠিক এইভাবে (index.html-এ ইতিমধ্যেই সেট করা আছে):

| ফাইল | কোন ছবি |
|---|---|
| 01.jpg | খাদ্য/রেশন বিতরণ |
| 02.jpg | শীতবস্ত্র বিতরণ |
| 03.jpg | মেডিকেল ক্যাম্প |
| 04.jpg | শিক্ষা উপকরণ বিতরণ |
| 05.jpg | রক্তদান ক্যাম্পেইন |
| 06.jpg | বৃক্ষরোপণ / প্রশিক্ষণ |

আকার: প্রায় 1200×900 px (4:3), ফাইল সাইজ ২০০ KB-র মধ্যে রাখলে সাইট দ্রুত চলবে।
ছবি যোগ করার পর index.html-এ `<div class="shot reveal">` অংশটি এভাবে বদলান:

```html
<div class="shot reveal"><img src="gallery/01.jpg" alt="খাদ্য বিতরণ কর্মসূচি" /></div>
```
