# তাকওয়া টাচ ফাউন্ডেশন — অফিসিয়াল ওয়েবসাইট 🌿

> **Taqwa Touch Foundation** — মানবতার সেবায়, তাকওয়ার ছোঁয়ায়।
> সম্পূর্ণ স্ট্যাটিক (HTML/CSS/JS) ওয়েবসাইট + সোশ্যাল মিডিয়া প্রচারণা কিট। কোনো বিল্ড টুল বা সার্ভার লাগে না।

**লাইভ:** https://taqwa-touch-foundation.github.io/site/

---

## 📁 ফাইল স্ট্রাকচার

```
index.html          → পুরো মূল ওয়েবসাইট (একটি ফাইলেই সব সেকশন)
404.html            → ভুল লিংকে গেলে দেখানো পেজ
robots.txt / sitemap.xml → সার্চ ইঞ্জিনের জন্য
.nojekyll           → GitHub Pages-এ ফাইল অকারণ প্রসেস হওয়া আটকায়
assets/
  logo.svg          → লোগো (nav, footer, favicon)
  og-cover.png      → শেয়ার করলে যে ছবি দেখায় (Facebook/WhatsApp প্রিভিউ)
  fonts/            → বাংলা ফন্ট (self-hosted, ইন্টারনেট ছাড়াও চলে)
preview/            → ডিজাইন প্রিভিউ (হিরো + সম্পূর্ণ পেজের স্ক্রিনশট)
campaign/
  index.html        → প্রচারণা কিট পেজ (পোস্টার + প্ল্যান)
  poster-*.png      → ৩টি রেডি সোশ্যাল পোস্টার (১০৮০×১৩৫০)
  facebook-cover-1640x624.png   → পেজের কভার ফটো
  facebook-profile-512.png      → প্রোফাইল ছবি
  promotion-plan.md → ৩০ দিনের প্রচারণা প্ল্যান
  facebook-posts.md → ১০টি রেডি ক্যাপশন
posters/make_posters.py → পোস্টার জেনারেটর স্ক্রিপ্ট (লেখা বদলে আবার চালান)
gallery/README.md   → কর্মসূচির ছবি কোথায় বসাবেন
```

## 🧠 সাইট কীভাবে সৎ থাকে (পরিকল্পনা বনাম চলমান)

আমরা এখনো শুরু করেছি সামাজিক সেবার ছোট কাজ দিয়ে। তাই সাইটে দুইটা আলাদা জায়গা আছে:

1. **"যে কাজগুলো আমরা এখন করছি"** — রাস্তাঘাট, গরীব-অসহায়দের সহায়তা, চিকিৎসায় সহযোগিতা, পরিচ্ছন্নতা, সচেতনতা, তরুণদের সংগঠিত করা।
2. **"ইনশাআল্লাহ, পরিকল্পনা"** (হলুদ কার্ড) — শিক্ষা ও বৃত্তি, রক্তদাতা নেটওয়ার্ক, মেডিকেল ক্যাম্প, শীতবস্ত্র, কারিগরি প্রশিক্ষণ, বৃক্ষরোপণ।

👉 **কোনো কর্মসূচি শুরু হলে:** `index.html`-এ ওই কাজের লেখা ভবিষ্যৎ-কার্ড থেকে সরিয়ে উপরের কার্ডের তালিকায় বসিয়ে দিন, ব্যাজটা `চলমান` করে দিন, আর সাথে ছবি ও খরচের হিসাব যোগ করুন।
👉 ফেসবুক/ইউটিউবে রক্তদান বা শিক্ষাবৃত্তির কথা বলার সময় "এখনো শুরু হয়নি, ইনশাআল্লাহ শুরু হবে" — এভাবে বললেই মানুষ বেশি বিশ্বাস করে।

| **কর্মসূচির ছবি** | `gallery/` ফোল্ডার | ছবি ছাড়া সেবার গল্প পৌঁছায় না — অগ্রাধিকার দিন |
| **ইউটিউব চ্যানেল** | যোগাযোগ সেকশনের `.socials` | লিংক পেলে বাটন যোগ করা হবে |
| **নিবন্ধন/সনদ নম্বর** | FAQ-এর নিবন্ধন প্রশ্নের উত্তর | হলে আস্থা অনেক বাড়ে |
| **ভবিষ্যৎ কর্মসূচি চালু হলে** | কার্যক্রম সেকশন | উপরের নিয়ম অনুযায়ী "পরিকল্পনা" → "চলমান" |

## 📷 গ্যালারিতে ছবি বসানো

1. ছবি `gallery/` ফোল্ডারে রাখুন — নাম: `01.jpg` … `06.jpg`
2. `index.html`-এ খুঁজুন: `<div class="shot reveal"><span>📷`
3. প্রতিটি অংশ এভাবে বদলান:

```html
<div class="shot reveal"><img src="gallery/01.jpg" alt="খাদ্য বিতরণ কর্মসূচি" loading="lazy" /></div>
```

## 📨 ফর্ম কোথায় যাবে?

দুটি ফর্মই সরাসরি **WhatsApp-এ মেসেজ** হিসেবে আসে — কোনো সার্ভার/ডাটাবেজ লাগে না।
`index.html`-এর স্ক্রিপ্টে একবার নম্বর বদলালেই সব ফর্ম কাজ করবে:

```js
var WA_NUMBER = "8801XXXXXXXXX"; // এখানে আপনার আসল নম্বর (দেশ কোড সহ)
```

চাইলে Google Form-ও ব্যবহার করতে পারেন: ফর্মের `action`-এ Google Form-এর লিংক বসিয়ে দিলে পয়েন্ট-এন্ড-ক্লিক রেসপন্স পাবেন।

## 🎨 পোস্টারের লেখা/নম্বর বদলানো

```bash

cd posters
python3 make_posters.py
```
লেখা বদলাতে `make_posters.py`-এর ভেতরের টেক্সট এডিট করুন; নতুন PNG `campaign/` ফোল্ডারে সেভ হবে।
